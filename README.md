# Trova bandi

Strumento di primo orientamento su bandi e finanza agevolata.

- `index.html` – la pagina (non va modificata per aggiornare i bandi)
- `bandi.json` – l'elenco dei bandi: è l'unico file che l'aggiornamento automatico modifica
- `CHANGELOG.md` – cosa è cambiato a ogni aggiornamento
- `CNAME` – dominio personalizzato per GitHub Pages

- `google-apps-script.gs` – codice da incollare nel foglio Google che raccoglie le richieste del modulo "Vuoi una mano con questi bandi?"
